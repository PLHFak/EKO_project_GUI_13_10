# EKO — documentation projet et interface (13/10)

Page « EKO en car / EKO in the OB van » : intégration autonome d'EKO dans un car régie, sons rendus au replay, Video Follow, console opérateur (service web) et claviers à touches-écrans. Bilingue FR / EN (bouton en haut de page, ou `#en` / `#fr` dans l'adresse).
